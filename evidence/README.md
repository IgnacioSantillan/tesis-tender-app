# Evidencia

Este directorio almacenara evidencia usada por la tesis final.

Ejemplos:

- Capturas del prototipo.
- Capturas de la aplicacion Android.
- Resultados de builds.
- Resultados de pruebas.
- Diagramas exportados.
- Registros de revision humana.
- Bitacora de incrementos de implementacion.

## Regla

Toda evidencia debe indicar fecha, origen, artefacto relacionado y capitulo donde se utiliza.

## Artefactos vivos

- `increment-log.md`: registro progresivo de tareas aprobadas, cambios realizados, verificacion y uso previsto dentro de la tesis.
- `increment-synthesis.md`: sintesis por incremento de valor, capitulos afectados, evidencia disponible y pendientes para acelerar la redaccion.
- `apa-visual-evidence-guide.md`: guia de tratamiento academico de figuras, tablas, notas APA, capturas y diagramas Mermaid.
- `screenshots/`: capturas visuales de incrementos implementados, usadas como evidencia para la tesis final.
- `screenshots/README.md`: indice de capturas por version visual, con reglas de uso y pendientes de clasificacion.
- `smoke-tests/`: registros de smoke tests locales o desplegados, con resultados, limites y pendientes sin exponer secretos.

## Uso recomendado para redaccion

Para redactar o regenerar la tesis, usar primero `increment-synthesis.md` como mapa de lectura y luego volver a `increment-log.md` solo cuando haga falta citar una tarea, verificacion o pendiente especifico.
