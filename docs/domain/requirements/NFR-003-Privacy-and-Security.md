# NFR-003 — Privacy and Security

## Purpose

Define a quality attribute for TenderApp: Privacy and Security.

## TenderApp Adaptation

The system shall minimize personal data, protect user sessions, and avoid exposing backend secrets in the mobile app.

## Engineering Notes

Rationale: Authentication, location, and history require careful handling.
