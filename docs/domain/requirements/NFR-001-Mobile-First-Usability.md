# NFR-001 — Mobile First Usability

## Purpose

Define a quality attribute for TenderApp: Mobile First Usability.

## TenderApp Adaptation

The mobile UI shall prioritize immediate understanding, minimal input, readable cards, and one-handed use.

## Engineering Notes

Rationale: TenderApp must communicate the wash/no-wash decision quickly.
