# REQ-008 — Settings and Preferences

## Purpose

Define a functional requirement for TenderApp: Settings and Preferences.

## TenderApp Adaptation

The system shall allow users to configure notification preferences, preferred drying location, default washer, and units.

## Engineering Notes

Rationale: Preferences reduce repeated input and improve usability.

## Traceability

Will be linked to UC, BR, UI, API, DB, and TEST artifacts in later releases.
