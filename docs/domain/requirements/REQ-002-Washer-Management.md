# REQ-002 — Washer Management

## Purpose

Define a functional requirement for TenderApp: Washer Management.

## TenderApp Adaptation

The system shall allow users to create, edit, view, and delete washer profiles.

## Engineering Notes

Rationale: Washer metadata improves personalization and enables realistic laundry workflows.
